# v114 — Visual moderno, simples e inteligente

- Paleta unificada para modo claro e escuro: neutros + vermelho Shogatsu.
- Redução de cores decorativas e sombras; status continuam diferenciados sem pintar cartões inteiros.
- Navegação móvel com barra inferior de 5 atalhos.
- Cardápio reorganizado para uso por toque no celular.
- Categorias agora usam automaticamente a primeira foto de produto como capa visual, mostrando quantidade e disponibilidade.
- Itens do cardápio priorizam foto, nome, descrição e preço, com ações compactas.
- Editor de produto simplificado: foto + nome + preço + descrição ficam em primeiro plano; opções avançadas (destaque e variações) ficam recolhidas em “Mais opções”.
- Mantidas as funções de upload, edição, disponibilidade, ocultação, exclusão e reordenação existentes.
- Não altera API ou formato dos dados.
